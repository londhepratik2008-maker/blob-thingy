# J.A.R.V.I.S. Holographic AI Core

A voice-reactive 3D holographic sphere web page inspired by J.A.R.V.I.S. from the MCU.

## Live Demo

**[Click here to view](https://londhepratik2008-maker.github.io/blob-thingy/index.html)**

## Features

- Blue + amber orbital rings with Saturn-like wobble
- Central glowing orb with 3 nested wireframe layers
- 4000+ data stream particles
- 80 floating digital nodes
- Intense bloom post-processing
- Voice reactivity — click "speak here" to activate mic
- Speech synthesis output on stop
